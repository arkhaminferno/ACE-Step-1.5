# HAYA After Effects template

Shipped with batch_deephouse so Mac/Windows clones can render YouTube visualizers.

- **Project:** `Haya songs.aep`
- **Assets:** `assets/` (background stills, logo, overlay MP4s, copyright PNG)
- **Edit comp:** `EDIT HERE` (title text layer `Yalil` → Arabic song title)

Per-song background stills live in `assets/` (Yalil uses `bd4a5f15-a571-44f2-a9e0-349a48312fa3.png`).
